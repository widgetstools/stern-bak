here is **frozen and unmaintained** — it describes deleted machinery
(`propagate`/`libs/`, pre-collapse package names, the `apps/demos/` era) or
completed one-time efforts. The current documentation set is
[`docs/latest/`](../latest/README.md); for the story behind any file here,
use git history.
